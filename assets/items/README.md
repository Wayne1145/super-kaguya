# Super Kaguya power items

- `muffin.png` is the user-provided 32 x 32 muffin sprite.
- `omelette-source.webp` is the user-provided source image.
- `omelette.png` is a 48 x 32 nearest-neighbor game asset, cropped from the
  source and made transparent by `tools/process-omelette.cjs`.

The crescent star and lunar fireball are drawn directly by the Canvas renderer,
so they do not require external art assets.
