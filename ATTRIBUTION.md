# Attribution and distribution notes

## Sushi items

The local source collection under `assets/food/source/` came from the archive
supplied by the project owner and identifies Kyukei (`Kyukei_dot`) as its
creator. The supplied terms allow game use and modification but prohibit
redistribution or resale of the raw source assets. It remains Git-ignored.

If it is included in a private build, retain `assets/food/README.md` plus the
two supplied source readmes and credit `Kyukei_dot` where practical.

## User-provided artwork

`assets/kaguya.png`, `assets/enemy1.png`, `assets/health.png`, `assets/score.png`
and the item inputs were supplied by the project owner for this project. Confirm
the intended publication rights before publishing a build containing them.

`assets/backgrounds/lunar-town-reference.png` is the project-owner supplied
reference image used as a low-opacity in-game background layer.

## Reference material

`references/` contains local research/reference files only. It is not part of
the distributable project and is ignored by Git.
